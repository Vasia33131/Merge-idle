# Cat Merge Idle

Расслабляющая idle-игра про котят. Покупаете котёнка, соединяете двух одинаковых в кота следующего уровня, а коты бродят по комнате и приносят монеты. Есть 15 уровней котов, улучшения, престиж («переезд» в новый дом за рыбок), офлайн-доход, русский и английский языки. Целевая платформа: **WebGL** (Яндекс Игры, CrazyGames и т. п.).

## Стек

| Что | Версия / пакет |
|---|---|
| Движок | Unity **2022.3.62f1** (LTS) |
| Рендер | URP 14 (2D, `com.unity.render-pipelines.universal`) |
| Ввод | Input System 1.14 (`com.unity.inputsystem`) |
| UI | uGUI + TextMeshPro 3.0.7 |
| Анимации | DOTween (`Assets/Plugins/Demigiant`) |
| Тесты | Unity Test Framework, EditMode |

Спрайтов-арта пока нет: котики, пол и предметы это цветные заглушки (`Assets/_Project/Art/Placeholders`), которые заменяются настоящими картинками без правок кода.

## Запуск

1. Откройте папку проекта в Unity 2022.3.62f1 (другие 2022.3 обычно тоже подходят).
2. Откройте сцену `Assets/Scenes/SampleScene.unity` и нажмите Play.
3. Сцена создаётся кодом. Если она сломалась или вы меняли генераторы, пересоберите её: **Tools → CatMerge → Build Game Scene**.

## Структура

Весь код игры лежит в `Assets/_Project/Scripts`, по папкам:

| Папка | Что внутри |
|---|---|
| `Core/` | Чистая логика игры без Unity: `GameState` (коты в комнате, слияния), `Economy`, `Wallet`, `Upgrades`, `Prestige`, `Codex`, `OfflineIncome`, формулы баланса (`BalanceMath`), сохранение (`SaveData`, `FlatJson`). Покрыта тестами. |
| `Data/` | ScriptableObject-конфиги: `BalanceConfig`, `CatConfig`/`CatDatabase`, `UpgradeConfig`/`UpgradeDatabase`, `HomeDatabase`. Вся настройка баланса и внешнего вида делается здесь. |
| `Game/` | Связка всего в игре: `GameController`, `IncomeSystem` (доход и всплывающие монеты), `SaveService`, `CatMeows`. |
| `Views/` | Визуал мира: `Room` (площадь, где ходят коты), `CatView`, `CatWander`, `RoomDecor` (стена и пол дома), `RoomProps` (предметы улучшений в комнате), `RoomCameraFit` (камера под любой экран). |
| `Input/` | `DragController`: перетаскивание котов и слияние. |
| `UI/` | Панели: HUD, магазин, улучшения, каталог котов (Catpedia), престиж, настройки, офлайн-окно, стартовый экран, safe area. |
| `Localization/` | `LocalizationService`, `Loc`, `LocalizedText`. Строки лежат в `Assets/_Project/Resources/Localization/ru.json` и `en.json`. |
| `Platform/` | `IPlatformService`: сохранение, загрузка, язык. Сейчас есть только `EditorPlatform` (PlayerPrefs). SDK площадок добавляются сюда. |
| `Audio/` | `AudioService`, громкость, микшер. Мяуканье по уровням в `Assets/_Project/Audio/Meows`. |
| `Editor/` | Генераторы ассетов и сцены (см. ниже). |

Ассеты: `Assets/_Project/Settings` (конфиги), `Prefabs` (кот, всплывающая монета), `Fonts`, `Audio`, `Art`.

## Как это работает

- **Кот.** Данные (`CatData`) отдельно от отображения (`CatView`). `GameState` сам ничего не знает про Unity.
- **Слияние.** Перетащите кота на кота того же уровня, получится кот на уровень выше. Комната вмещает ограниченное число котов (12 + улучшение).
- **Экономика.** Каждый кот приносит монеты в секунду по своему уровню. Множитель даёт улучшение «Кошачья мята» и рыбки. Новые котята покупаются только в магазине (цена растёт с каждой покупкой).
- **Улучшения.** Места в комнате, множитель дохода, лимит и доля офлайн-дохода, «лучший котёнок». Описание и цены в `UpgradeConfig`.
- **Престиж.** «Переезд» сбрасывает прогресс, даёт рыбок (постоянный бонус к доходу) и меняет дом (стена и пол из `HomeDatabase`).
- **Офлайн.** При возвращении игрока начисляется доля дохода за время отсутствия, с лимитом по часам.
- **Комната.** Горизонтальная 9×6 и вертикальная 6,4×8,4 единицы; `RoomCameraFit` выбирает форму по экрану и подгоняет камеру между верхней и нижней частью HUD.
- **Сохранение.** Через `IPlatformService` строкой JSON (`SaveData`, `FlatJson`).

## Меню инструментов

Все в **Tools → CatMerge**:

| Пункт | Что делает |
|---|---|
| Build Game Scene | Собирает сцену, камеру, HUD и все панели кодом. |
| Generate Cat Configs | Создаёт 15 конфигов котов и пересчитывает доход по `BalanceConfig`. Свои спрайты и звуки не трогает. |
| Generate Upgrade Configs | Создаёт конфиги улучшений. Уже существующие не перезаписывает. |
| Generate Home Configs | Создаёт дома. Уже существующую базу не трогает. |
| Generate Fonts | Создаёт шрифты TextMeshPro. |
| Create Audio Mixer | Создаёт аудио-микшер. |
| Print Balance Table | Печатает таблицу баланса по уровням (также в контекстном меню `BalanceConfig`). |

## Как подставить свой арт

| Что | Где | Размер |
|---|---|---|
| Кот (по уровням) | `CatConfig → Sprite` в `Settings/Cats` | 512×512, PPU = ширина (кот = 1 единица) |
| Пол дома, горизонтальный | `HomeDatabase → Floor Sprite` | 2304×1536, PPU = ширина |
| Пол дома, вертикальный | `HomeDatabase → Floor Sprite Portrait` | 1638×2150, PPU = ширина |
| Предметы улучшений в комнате | `UpgradeConfig → Prop Sprites` (по спрайту на стадию, до 3) | 256–512 px, PPU = ширина |
| Мяуканье | `CatConfig → Meow Clip` | |

Пока нет картинок, вместо них показываются цветные заглушки.

## Тесты

**Window → General → Test Runner → EditMode**. Тесты проверяют ядро: баланс, экономику, состояние игры, улучшения, сохранение, локализацию, форматирование чисел (`Assets/_Project/Tests/EditMode`).

## Решения по проекту

- Свободная комната без сетки: коты ходят где хотят.
- Новые котята только из магазина, без автоспавна.
- Платформа: WebGL, рекламные и облачные SDK добавляются через `IPlatformService`.
- Локализация: русский и английский, язык берётся у платформы.
