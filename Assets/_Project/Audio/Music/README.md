# Фоновая музыка

Один спокойный зацикленный трек (lo-fi / акустика, 1–3 мин, бесшовная петля), `.ogg` или `.mp3`.
Импорт: Load Type **Streaming**, Compression Vorbis ~50–60.

После добавления: `Tools/CatMerge/Build Game Scene` (подставит первый трек из этой папки)
или вручную в `Audio → AudioService → Music Clip`. Трек плавно появляется после «Нажми, чтобы начать».
