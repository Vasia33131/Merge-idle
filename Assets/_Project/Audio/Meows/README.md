# Мяуканья котов

Сюда кладём по одному звуку «мяу» на каждый уровень кота (всего 15).

## Имена файлов

| Файл         | Кот                 | Характер звука (идея)              |
|--------------|---------------------|------------------------------------|
| `Meow_01.wav`| Котёнок             | тонкий, короткий писк              |
| `Meow_02.wav`| Пушистик            | мягкий, «пушистый»                 |
| `Meow_03.wav`| Рыжик               | звонкий, бодрый                    |
| `Meow_04.wav`| Полосатик           | быстрый, двойной «мя-мяу»          |
| `Meow_05.wav`| Соня                | сонный, с зевком                   |
| `Meow_06.wav`| Батон               | ленивое «мрр-мяу»                  |
| `Meow_07.wav`| Пухляш              | низкий, округлый                   |
| `Meow_08.wav`| Леди Усы            | изящный, вежливый                  |
| `Meow_09.wav`| Сэр Мяулингтон      | важный, протяжный                  |
| `Meow_10.wav`| Кот-ниндзя          | короткий, тихий, резкий            |
| `Meow_11.wav`| Кот-волшебник       | мяу с лёгким «звяк»/эхом           |
| `Meow_12.wav`| Кот-рокер           | мелодичный, «в ноту»               |
| `Meow_13.wav`| Кот-астронавт       | с радио-фильтром                   |
| `Meow_14.wav`| Кошачий король      | глубокий, величественный           |
| `Meow_15.wav`| Космический кот     | с ревербом, «звёздный»             |

Номер в имени = уровень кота. Подходят `.wav`, `.ogg`, `.mp3` — главное, чтобы имя
без расширения было ровно `Meow_XX`.

## Требования к звуку

- Длина 0.3–1.2 сек, без тишины в начале (иначе мяу «запаздывает» после тапа).
- Моно, 44.1 кГц. Громкость выровнять между уровнями (около −14…−12 LUFS / пик −1 dB).
- Pitch каждый раз случайно сдвигается на ±6%, так что отдельные вариации не нужны.
- Лицензия: CC0 или своя запись (для Яндекс Игр / CrazyGames важна чистая лицензия).

## Настройки импорта в Unity

- Load Type: **Decompress On Load** (короткие клипы, без задержки).
- Force To Mono: вкл. Compression: Vorbis, Quality ~70.
- Preload Audio Data: вкл.

## Как подключить

1. Положить файлы сюда.
2. `Tools/CatMerge/Generate Cat Configs` — пустые слоты `meowClip` в `Settings/Cats/Cat_XX.asset`
   заполнятся автоматически по имени. Уже назначенные клипы не перезаписываются.
   (Можно и вручную перетащить клип в поле `Meow Clip` нужного `Cat_XX`.)

Пока файла нет — всё работает: кот «мяукает» беззвучно (только покачивается).

## Музыка

Фоновую музыку кладём в `Assets/_Project/Audio/Music/` (один зацикленный трек, `.ogg`/`.mp3`,
Load Type: **Streaming**). После этого `Tools/CatMerge/Build Game Scene` подставит первый найденный
трек в `Audio → AudioService → Music Clip` (или перетащить вручную).
